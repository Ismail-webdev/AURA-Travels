# AURA Travels 🌍

A modern, premium, and fully responsive travel website built using only **HTML, CSS, and JavaScript**.

This project was created as a frontend showcase to demonstrate responsive web design, clean UI development, and interactive frontend functionality without using frameworks or libraries.

---

## ✨ Features

- Fully responsive design
- Modern premium UI
- Smooth scrolling navigation
- Interactive destination filtering
- JavaScript testimonial slider
- FAQ accordion section
- Elegant booking form
- Hover animations and micro-interactions
- Mobile-friendly layouts
- Clean and structured codebase

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 🎯 Project Goals

The goal of this project was to create a visually engaging travel brand website experience while focusing on:

- Responsive frontend development
- Clean UI/UX design
- Interactive website components
- Modern layout structure
- Real-world business presentation

---

## 📱 Responsive Design

The website is optimized for:
- Mobile devices
- Tablets
- Desktop screens
